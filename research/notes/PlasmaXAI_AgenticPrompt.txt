RESEARCH TITLE:

--------------------------------------------------------------------------------

================================================================================
PROBLEM STATEMENT
================================================================================

Multiple Myeloma (MM) is a haematological malignancy originating in plasma cells
of the bone marrow. Diagnosis requires expert pathologists to manually examine
Wright-Giemsa stained bone marrow aspirate slides — a process that is:

  - Slow: manual examination takes 30-90 minutes per patient
  - Subjective: inter-observer variability among pathologists is high
  - Inaccessible: bone marrow pathology experts are critically scarce in
    Bangladesh and other developing countries
  - Black-box: existing AI models output binary labels (malignant/benign)
    with zero clinical explanation

CRITICAL GAP:
All published MM detection AI systems fail in two ways:
  1. They produce unexplainable black-box decisions that clinicians cannot
     verify or trust — especially in the absence of a specialist
  2. They provide no actionable feedback: a clinician cannot determine WHICH
     morphological features drove the diagnosis or WHAT would need to change
     for a borderline cell to be reclassified

This makes existing AI tools clinically unusable in rural or resource-limited
hospital settings where expert validation is unavailable.

================================================================================
RESEARCH OBJECTIVES
================================================================================

Objective 1: CLASSIFICATION
  Train an EfficientNet-B0 deep learning classifier on the PCMMD dataset
  to distinguish malignant plasma cells from non-plasma cells with >90%
  accuracy, sensitivity ≥ 0.90 for the malignant class (clinical threshold).

Objective 2: COUNTERFACTUAL EXPLANATION GENERATION
  Apply the DICE (Diverse Counterfactual Explanations) framework to generate
  per-cell "what-if" explanations answering: "What morphological features,
  if changed minimally, would flip this cell's diagnosis from malignant to
  benign?" This gives clinicians actionable, cell-specific diagnostic feedback.

Objective 3: CLINICAL FEATURE BOUNDARY IDENTIFICATION
  Extract and rank the top morphological features (nucleus-cytoplasm ratio,
  nucleus area, cytoplasm area, staining intensity, granularity, roundness,
  RGB channel intensities) that most frequently appear in counterfactual
  explanations — revealing what the model uses to distinguish MM plasma cells
  at a clinically interpretable level.

Objective 4: PATIENT-LEVEL VALIDATION
  Using PCMMD Set 2 (2,021 cells organized by patient with MM/non-MM diagnoses),
  validate whether cell-level counterfactual morphological patterns aggregate
  consistently at the patient level — i.e., do MM-positive patients show
  reproducible counterfactual morphological signatures across their cells?

Objective 5: DEPLOYMENT FEASIBILITY IN LOW-RESOURCE SETTINGS
  Profile the full PlasmaXAI pipeline (classification + counterfactual
  generation) for CPU inference time (target: <500ms per cell) and memory
  usage — demonstrating viability for hospitals in Bangladesh and other
  developing countries without specialized GPU infrastructure.

Objective 6: MULTI-MODEL BENCHMARKING
  Compare PlasmaXAI against ResNet-50, VGG-16, MobileNetV2, Random Forest,
  and SVM baselines across Accuracy, Weighted F1, Precision, Recall, AUC-ROC,
  inference time, and parameter count.

================================================================================
METHODOLOGY PIPELINE
================================================================================

Stage 1 — Data Preparation
  Input: PCMMD Set 1 (3,546 cells) + Set 3 (segmented)
  Steps: Resize to 224x224, normalization (ImageNet stats),
         augmentation (flip, rotation, color jitter),
         weighted random sampling for class balance

Stage 2 — Morphological Feature Extraction (for DICE)
  Features extracted per cell using OpenCV:
    - Nucleus area (proportion of cell area)
    - Cytoplasm area
    - Nucleus-Cytoplasm (NC) ratio [primary MM indicator]
    - Staining intensity (Wright-Giemsa darkness)
    - Granularity (Laplacian variance — texture measure)
    - Cell roundness (contour-based circularity)
    - Mean RGB channel intensities (R, G, B)

Stage 3 — Deep Learning Classification
  Architecture: EfficientNet-B0 (pretrained ImageNet, fine-tuned)
  Training: 30 epochs, AdamW optimizer, CosineAnnealingLR scheduler,
            CrossEntropyLoss, WeightedRandomSampler
  Split: 70% train / 15% val / 15% test (stratified, seed=42)

Stage 4 — Counterfactual Explanation Generation (DICE)
  Framework: DICE-ML (Diverse Counterfactual Explanations)
  Input: Morphological feature vectors of malignant plasma cells
  Output: Minimum feature perturbations that flip diagnosis to benign
  Parameters: 3 CFs per cell, proximity_weight=0.5, diversity_weight=1.0
  Analysis: Rank features by frequency and magnitude in counterfactuals

Stage 5 — Patient-Level Validation
  Input: PCMMD Set 2 cell features grouped by patient
  Method: Aggregate counterfactual signatures per patient,
          correlate with patient-level MM diagnosis
  Metric: Pearson correlation, patient-level AUC

Stage 6 — Deployment Profiling
  Hardware: Standard CPU (no GPU)
  Metric: Inference time (ms per cell), RAM usage (MB)
  Target: <500ms per cell for real-time clinical use
