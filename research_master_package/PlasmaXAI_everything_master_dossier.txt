PlasmaXAI Everything Master Dossier

Purpose of this file
--------------------------------------------------------------------------
This is the full detailed master record for the PlasmaXAI project. It is
meant to go beyond a short abstract, short summary, or competition brief.
It documents the scientific background, problem definition, research
motivation, objectives, scope, methodology, architecture evolution,
results, robustness studies, explainability findings, website/deployment
translation, artifact inventory, GitHub push status, and practical
limitations.

This file is intended to answer the question:
"What exactly is PlasmaXAI, how was it built, what did it achieve, what
is original about it, what is deployable, what has been pushed to GitHub,
and what remains limited or excluded?"


1. Project identity and naming history
--------------------------------------------------------------------------
Final preferred project name:
PlasmaXAI

Earlier names used during development:
- PlasmaXNet
- PLASMAXNET

High-level description:
PlasmaXAI is a counterfactual-guided explainable AI framework for the
recognition of malignant plasma cells in multiple myeloma microscopy
images. The project started as a notebook-driven classification study,
then progressed through benchmark optimization, and finally matured into
a learned fusion framework with explainability inside the decision path,
patient-level analysis, paper materials, and a doctor-facing website.

Core project idea:
The project is not only about classifying images. Its central idea is to
combine:
- deep image embeddings
- explicit morphology features
- counterfactual boundary information
- clinician-oriented explainability
- doctor-facing review workflow

So the final project is best described as:
"an explainable digital hematopathology framework plus a clinical review
workspace"


2. Background and problem context
--------------------------------------------------------------------------
Clinical context:
Multiple myeloma is a hematologic malignancy characterized by abnormal
clonal proliferation of plasma cells. Morphologic examination of bone
marrow and plasma-cell images remains clinically relevant in diagnosis,
follow-up, burden estimation, and disease interpretation.

Why the problem matters:
- Plasma-cell review is time-consuming.
- Morphology interpretation can vary with expertise.
- Large image volumes are difficult to screen manually.
- Lower-resource settings may not have enough specialist capacity.
- Many AI systems optimize only for accuracy and do not give doctors
  useful reasons for their decisions.

Practical gap addressed by PlasmaXAI:
There is a need for an AI system that is:
- accurate enough to be clinically interesting
- explainable in a doctor-usable way
- not just a black-box classifier
- translatable into a real review workflow

Project problem statement:
Can we build a high-performing malignant plasma-cell recognition system
that not only improves diagnostic support on microscopy images, but also
explains its reasoning in a way that is useful to doctors rather than
only to machine-learning developers?


3. Research objectives
--------------------------------------------------------------------------
Primary objectives:
1. Build a strong malignant plasma-cell recognition model on PCMMD.
2. Compare it against established deep and morphology-only baselines.
3. Improve over the original notebook-stage framework.
4. Move explainability into the decision path instead of attaching it
   only after prediction.
5. Explore patient-level signal consistency using grouped case analysis.
6. Package the work for paper, figures, reports, and a doctor-facing
   website.

Secondary objectives:
1. Improve both plasma precision and plasma recall at the final selected
   operating point.
2. Support claims with ablation and bootstrap evidence.
3. Produce clinician-readable report material.
4. Provide architecture diagrams and competition-ready documentation.

Scope:
This project covers:
- dataset usage
- model development
- benchmark comparison
- explainability
- counterfactual analysis
- statistical robustness
- patient-level interpretation
- report generation
- website-based clinical workflow translation

8. Why the project still needed a stronger novelty claim
--------------------------------------------------------------------------
At the end of phase 2, the system was strong but not deeply novel from a
methodological perspective. The main limitations were:
- ensemble weighting was mostly static
- explainability was still too external to the final decision
- there was no deeper patient-level interpretation story
- the system did not yet strongly differentiate itself as a research
  framework rather than an optimized benchmark

This led to the decision to build a truly learned fusion framework and
to tie counterfactual information into the model’s decision pathway.

9.1 Core design idea
PlasmaXAI combines:
- frozen ResNet50 image embeddings
- frozen DenseNet121 image embeddings
- handcrafted morphology features
- a morphology-derived counterfactual boundary model
- learned gating and fusion

This means the final system is neither a plain CNN nor a simple
weighted-average ensemble.

9.2 Deep image pathways
Image branches:
- ResNet50 branch
- DenseNet121 branch

Role:
These capture texture, chromatic structure, cell architecture, and other
high-dimensional visual patterns from microscopy images.

9.3 Morphology pathway
The morphology branch encodes explicit interpretable features such as:
- nucleus-to-cytoplasm ratio
- nucleus area
- cytoplasm area
- roundness/shape information
- staining characteristics
- mean RGB descriptors
- related transformed ratios and summary descriptors

Role:
This preserves interpretable morphologic structure and helps connect the
framework to clinically meaningful cues rather than only latent image
features.

9.4 Counterfactual pathway
This is one of the most important components of the project.

Instead of producing counterfactuals only after classification, the
framework computes a morphology-based boundary representation that
describes:
- how far a case lies from a benign decision region
- which feature shifts would move the case toward a lower-suspicion
  region

These counterfactual signals are then fed into the learned fusion model
itself.

9.5 Learned fusion
The final fusion architecture includes:
- modality-specific encoders
- sigmoid gates modulated by counterfactual information
- a softmax modality-gating stage for weighted fusion
- a final classification head

This makes the explainability path structurally relevant to the final
decision.

9.6 Best fusion configuration

17. Originality and innovation claim
--------------------------------------------------------------------------
Strongest originality points:
1. Counterfactual information is embedded into the decision path instead
   of only being shown after prediction.
2. The final system is a learned fusion module, not just a fixed
   weighted ensemble.
3. The framework combines deep image features, morphology, and
   counterfactual signals in one architecture.
4. The project extends into patient-level consistency analysis.
5. The work is translated into a doctor-facing interface rather than
   stopping at a model checkpoint.

Honest wording:
PlasmaXAI is novel as a framework/system and as a counterfactual-guided
learned fusion approach. It is not claimed here to be a radically new
fundamental family of neural architecture in the same sense as inventing
an entirely new backbone class from scratch.
